# Aula 5:  Ferramentas de Processamento em Larga Escala

* **Desafio**: Lidar com grandes volumes de dados que excedem a capacidade de processamento de máquinas convencionais.
* **Solução**: Utilização de arquiteturas em clusters computacionais, como o Hadoop, para armazenar e processar dados em larga escala.

## Hadoop

* **HDFS (Hadoop Distributed File System)**: Sistema de arquivos distribuído para organizar o armazenamento em clusters.
* **MapReduce**: Modelo de programação para processamento paralelo de dados.
* **YARN (Yet Another Resource Negotiator)**: Gerenciador de recursos computacionais.

## Processamento

> *Em busca do formato e dados adequados para otimizar o desempenho e a eficácia das operações de análise...*

* **Pré-Processamento dos Dados** Remoção de dados irrelevantes; Tratamento de valores ausentes; Padronização de formatos; Detecção e correção de erros;

* **Transformação e Enriquecimento de Dados** Criação de novas variáveis (variáveis derivadas); Junções e Agregação de dados; Redução de dimensionalidade.

* **Data Cleaning, Normalização e Interpolação** Data cleaning... valores ausentes? outliers?

* **Engenharia de Recursos** Modelagem, Seleção de Features (ganho de informação, outros), *Geração de Dados sintéticos*.
